## Context

I come from the background of Machine learning where applications undergo severe evaluation checks before getting deployed and metrics made more sense. Since I come from Machine learning I was also aware of the stochastic nature of the large language models and building inference services with them made me realize one thing early on. If we need to build applications with LLM simple prompts aren't going to suffice and that there should some way to structure the prompts as inputs and then get structured outputs out of the LLM

## Instructor

While I was getting this thesis in my mind that inputs have to be structured an idea struck my mind why not pydantic models to validate the outputs of JSON demand from the LLM. When I went to implement this library I went to check if anything was available already for this and [Instructor](https://python.useinstructor.com/) caught my eye.
